# Hello World

Eine kleine Website mit HTML, CSS und JavaScript. Keine Installation und keine zusätzlichen Pakete nötig.

## Öffnen

Öffne `index.html` direkt im Browser. Über „Sag Hallo“ erscheint eine Begrüßung.

Alternativ mit Python 3 aus dem Repository starten:

```sh
cd /workspace/codex/projekte/hello-world
python3 -m http.server 8000 --bind 127.0.0.1
```

Der Server lässt sich mit `Strg+C` beenden. In einer lokalen Entwicklungsumgebung ist die Website dann unter `http://127.0.0.1:8000` erreichbar. Die Codex-Onboarding-Oberfläche stellt dafür keine öffentliche Vorschau bereit.

## Dateien

- `index.html`: Inhalt und Struktur
- `style.css`: Farben und Layout
- `script.js`: Interaktion des Buttons

Weitere eigenständige Projekte kommen als eigene Ordner neben `hello-world` unter `projekte/`.
